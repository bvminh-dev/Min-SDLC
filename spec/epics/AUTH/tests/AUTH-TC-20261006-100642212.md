## Các bước
- **Given** admin `a1`, customer `u1` active với hai phiên
- **When** gọi `POST /api/v1/admin/users/{u1.id}/lock` với `{"reason": "gian lận thanh toán"}`
- **Then** trả 200 `status` = `locked`; `u1.locked_reason` = `admin`, `locked_until` rỗng; cả hai phiên `revoked` (`admin_lock`); có OutboxEvent UserLocked (`reason` = `admin`) và hai SessionRevoked ghi cùng giao dịch; có AuditLog (admin, `u1`, khóa, lý do); `u1` đăng nhập mật khẩu đúng trả 401 `invalid_credentials`

- **Given** `u1` đang `locked` (admin)
- **When** gọi `POST .../unlock`
- **Then** trả 200 `status` = `active`; `failed_login_count` = 0; có AuditLog; không có event mới (UserUnlocked ở backlog); `u1` đăng nhập lại được

## Dữ liệu và ghi chú
Dữ liệu mồi dựng bằng fixture; đồng hồ giả cho các mốc thời gian; kiểm event bằng cách bắt bus nội bộ.
