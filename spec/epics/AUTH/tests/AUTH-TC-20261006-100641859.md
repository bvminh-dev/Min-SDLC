## Các bước
- **Given** token không tồn tại, `used`, `expired`, và token của user bị admin khóa
- **When** gọi reset với từng token
- **Then** cả bốn trả 400 `invalid_or_expired_token` cùng nội dung; không đổi dữ liệu

- **Given** token `T` hợp lệ
- **When** gửi `new_password` 9 ký tự, rồi bằng email
- **Then** trả 400 `validation`; token vẫn `issued`; gửi lại với mật khẩu hợp lệ thành công

- **Given** guest
- **When** gọi reset thiếu `token`, rồi thiếu `new_password`
- **Then** trả 400 kiểm schema

- **Given** một IP đã gọi reset 10 lần trong giờ
- **When** gọi lần thứ 11
- **Then** trả 429 kèm `Retry-After`

## Dữ liệu và ghi chú
Dữ liệu mồi dựng bằng fixture; đồng hồ giả cho các mốc thời gian; kiểm event bằng cách bắt bus nội bộ.
