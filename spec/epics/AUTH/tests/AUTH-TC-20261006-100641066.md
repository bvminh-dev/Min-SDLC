## Các bước
- **Given** một token `issued` còn hạn
- **When** gửi hai request xác minh cùng token song song
- **Then** đúng một trả 200 và một OutboxEvent EmailVerified; request kia trả 400

- **Given** token còn 1 giây hạn và token đã quá hạn 1 giây (đồng hồ giả)
- **When** gọi xác minh từng token
- **Then** token còn hạn trả 200; token quá hạn trả 400

- **Given** `u2` đăng nhập, token thuộc `u1`
- **When** `u2` gọi xác minh bằng token của `u1`
- **Then** `u1` được xác minh; `u2` không đổi; phiên `u2` không đổi

- **Given** `u1` đã xác minh, mở lại link cũ
- **When** gọi xác minh với token đã `used`
- **Then** trả 400 `invalid_or_expired_token`

- **Given** một token `issued` còn hạn
- **When** gửi `GET /api/v1/auth/verify-email?token=T` (như bộ quét link)
- **Then** trả 404 hoặc 405; token vẫn `issued`; log máy chủ web của trang không chứa token (token ở fragment)

## Dữ liệu và ghi chú
Kiểm "log không chứa token" bằng cách chạy trang với log truy cập giả và tìm chuỗi token.
