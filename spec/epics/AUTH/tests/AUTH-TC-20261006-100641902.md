## Các bước
- **Given** một token `issued` còn hạn
- **When** gửi hai reset song song cùng token
- **Then** đúng một trả 200 và một OutboxEvent PasswordChanged; request kia trả 400

- **Given** `u1` đang khóa tạm vì sai mật khẩu (còn 8 phút), có token còn hạn
- **When** đặt lại thành công
- **Then** `failed_login_count` = 0 nhưng `status` vẫn `locked` và `locked_until` không đổi (`locked -> active` chỉ do hết hạn khóa hoặc admin mở); đăng nhập bằng mật khẩu mới trong lúc khóa trả 401 chung; sau khi đồng hồ giả qua hạn khóa thì đăng nhập thành công và `status` về `active`

- **Given** `u1` bị admin khóa, có token `issued` còn hạn (phát hành trước khi bị khóa)
- **When** gọi reset
- **Then** trả 400 `invalid_or_expired_token`; token không bị tiêu thụ

- **Given** token còn 1 giây hạn, rồi quá hạn 1 giây (đồng hồ giả)
- **When** gọi reset
- **Then** còn hạn trả 200; quá hạn trả 400

- **Given** token hợp lệ
- **When** gửi mật khẩu 128 ký tự rồi 129 ký tự
- **Then** 128 thành công; 129 trả 400 `too_long`

## Dữ liệu và ghi chú
Dữ liệu mồi dựng bằng fixture; đồng hồ giả cho các mốc thời gian; kiểm event bằng cách bắt bus nội bộ.
