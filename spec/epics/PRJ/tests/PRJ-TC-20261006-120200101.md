## Các bước
- **Given** **Given** Repo có `.nvmrc` = `24`, `engines.node` = `>=24 <25`, `.npmrc` có `engine-strict=true`; một máy chạy Node 22.11.0 và một máy chạy Node 24.1.0
- **When** Chạy `pnpm install --frozen-lockfile` trên từng máy
- **Then** Máy Node 22.11.0: lệnh thoát mã khác 0 và thông báo nêu `engines.node` không khớp, không tạo `node_modules`; máy Node 24.1.0: cài đặt thoát mã 0; `pnpm test` chạy bằng Jest trên `apps/api` và không có cấu hình công cụ test thứ hai

## Dữ liệu và ghi chú
Căn cứ PRJ-REQ-20261006-095422475 BR7. Chạy trong hai container CI có Node 22 và Node 24.
