## Các bước
- **Given** Customer đã đăng nhập gọi một endpoint trả 200; bắt stdout
- **When** Request kết thúc
- **Then** Đúng một dòng JSON hợp lệ có `time`, `level` = `info`, `correlation_id` bằng `X-Request-Id` phản hồi, `method`, `route`, `status` = 200, `duration_ms` >= 0, `user_id`; không có `Authorization`, `Cookie` hay thân request
