## Các bước
- **Given** Mã giả định: module `catalog` import file bên trong module `order`; module `order` import module `payment` (ORD chỉ phụ thuộc AUTH)
- **When** CI chạy kiểm ranh giới module
- **Then** Kiểm thoát mã khác 0; thông báo nêu từng vi phạm gồm tệp, module nguồn, module đích và quy tắc (không có trong Phụ thuộc, hoặc import vào tệp bên trong)

## Dữ liệu và ghi chú
Fixture: hai tệp vi phạm trong thư mục thử; kiểm cả hai kiểu vi phạm trong một lần chạy.
