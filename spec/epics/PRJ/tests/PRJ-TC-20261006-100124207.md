## Các bước
- **Given** Module `payment` có Phụ thuộc `order` đúng như `architecture.md`
- **When** CI chạy kiểm ranh giới với hai import: `payment` tới điểm vào công khai của `order`, và `order` tới `payment`
- **Then** Import xuôi qua; import ngược thất bại với thông báo nêu rằng liên lạc ngược chiều chỉ bằng domain event
