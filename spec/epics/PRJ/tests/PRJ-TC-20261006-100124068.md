## Các bước
- **Given** Máy sạch có Node và pnpm đúng phiên bản ghim, PostgreSQL local, đã tạo `.env` từ `.env.example`
- **When** Chạy `pnpm install --frozen-lockfile` rồi `pnpm dev`
- **Then** Lệnh cài đặt thoát mã 0; `GET /api/v1/health` trả 200 `{"status":"ok"}`; web trả 200 ở trang chủ; không phải sửa tệp nào ngoài `.env`

## Dữ liệu và ghi chú
Chạy trong container sạch ở CI (job smoke). Đo thời gian từ clone tới health 200, mục tiêu <= 15 phút theo README.
