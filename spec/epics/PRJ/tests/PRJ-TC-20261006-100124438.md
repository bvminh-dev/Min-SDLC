## Các bước
- **Given** Schema Prisma thêm một cột nhưng không có migration tương ứng
- **When** CI chạy kiểm lệch schema (`prisma migrate diff --exit-code`)
- **Then** Bước kiểm thoát mã khác 0 và nêu có khác biệt; sau khi thêm migration thì thoát mã 0
