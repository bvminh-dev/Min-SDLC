## Các bước
- **Given** Pull request sửa `package.json` thêm một phụ thuộc nhưng không cập nhật `pnpm-lock.yaml`
- **When** CI chạy `pnpm install --frozen-lockfile`
- **Then** Lệnh thoát mã khác 0 với lỗi lockfile lỗi thời; pull request đỏ; các bước sau không chạy

## Dữ liệu và ghi chú
Dựng nhánh thử có lockfile lệch.
