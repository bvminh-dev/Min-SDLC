## Các bước
- **Given** tạm tính 600000, coupon cố định giảm 200000 (sau giảm 400000); SM1 miễn phí từ 500000
- **When** A chọn SM1 và xem lại
- **Then** `shipping.fee` = 0, `shipping.free_shipping` = true, `shipping_fee` = 0
- **Then** `grand_total` = 600000 - 200000 + 0 = 400000

## Dữ liệu và ghi chú
Dữ liệu mồi: P1 giá 150000, P2 giá 50000; SM1 phí 30000, miễn phí từ 500000, phụ thu 50000 cho "Hà Giang"; SM2 phí 50000. CRT, USR, PRM, SHP, INV, ORD dùng module thật trên PostgreSQL; chỗ cần gài lỗi hay thời gian dùng bản giả bọc ngoài có đếm lời gọi.
