## Các bước
- **Given** phiên của A: P1 150000 x 2, P2 50000 x 1, SALE10 hợp lệ, địa chỉ city "Hà Nội", SM1 (30000), thanh toán `cod`; `cart_version` = 7; tồn đủ
- **When** A gọi GET /api/v1/checkout/sessions/{id}
- **Then** 200: `items_subtotal` = 350000, `discount` = 35000, `shipping_fee` = 30000, `grand_total` = 345000, `total_is_estimate` = false, `expected_grand_total` = 345000, `cart_version` = 7
- **Then** `blockers` rỗng, `can_place_order` = true, `payment_note` = `{ hold_minutes: null, confirmed_immediately: true }`; header `Cache-Control: no-store`; phản hồi không có `user_id`, `cart_id`, `price_snapshot`

## Dữ liệu và ghi chú
Dữ liệu mồi: P1 giá 150000, P2 giá 50000; SM1 phí 30000, miễn phí từ 500000, phụ thu 50000 cho "Hà Giang"; SM2 phí 50000. CRT, USR, PRM, SHP, INV, ORD dùng module thật trên PostgreSQL; chỗ cần gài lỗi hay thời gian dùng bản giả bọc ngoài có đếm lời gọi.
