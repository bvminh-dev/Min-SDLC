## Các bước
- **Given** Bản ghi A có on_hand 5, reserved 5
- **When** Chạy SQL trực tiếp đặt reserved = 6; đặt on_hand = -1; sau đó staff xuất 1
- **Then** Hai lệnh SQL bị CHECK từ chối, giá trị cũ giữ nguyên; xuất kho nhận 409 insufficient-stock với available = 0
