## Các bước
- **Given** Customer A đủ điều kiện cho P1, P2, P3
- **When** A tạo đánh giá P1 với comment gồm đúng 2000 chữ "a"; P2 với 2000 ký tự emoji "😀" (mỗi ký tự một code point); P3 với comment "   \n  "
- **Then** P1 và P2 nhận 201 với comment đủ độ dài (char_length = 2000)
- **Then** P3 nhận 201 với comment=null (chuỗi toàn khoảng trắng coi như không có)

## Dữ liệu và ghi chú
Cạnh đó 2001 ký tự là lỗi (TC lỗi của requirement). Độ dài tính theo code point sau khi cắt, không theo byte UTF-8.
