## 2. Vòng đời đánh giá và kiểm duyệt

```mermaid
flowchart TD
    N([Đánh giá mới]) --> PE[pending]
    PE -- Admin duyệt, hoặc tự động khi tắt kiểm duyệt trước --> PU[published]
    PE -- Admin từ chối kèm lý do --> RJ[rejected]
    PU -- Admin ẩn kèm lý do --> HD[hidden]
    HD -- Admin bỏ ẩn --> PU
    PU -- Chủ sửa khi bật kiểm duyệt trước --> PE
    PU -- Chủ sửa khi tắt kiểm duyệt trước --> PU
    PE -- Chủ sửa --> PE
    PE -- Chủ hoặc admin xóa --> DL[deleted]
    PU -- Chủ hoặc admin xóa --> DL
    RJ -- Chủ hoặc admin xóa --> DL
    HD -- Chủ hoặc admin xóa --> DL
    PU --> EV1{{ReviewPublished lúc vào published, kể cả bỏ ẩn}}
    PU --> EV4{{ReviewRatingChanged khi sửa điểm mà vẫn published}}
    HD --> EV2{{ReviewHidden lúc vào hidden, có rating}}
    DL --> EV3{{ReviewDeleted lúc vào deleted}}
    X{{Thao tác sai trạng thái}} --> E409[409 và không đổi, không phát event]
    RJ --> End([Trạng thái cuối ngoài xóa])
    DL --> End2([Trạng thái cuối])
```

Mọi event ghi vào outbox cùng giao dịch với đổi trạng thái (ADR-011); PRD giữ ProductReviewRating theo review_id để cập nhật điểm idempotent. Chuyển published sang pending chưa có event cho PRD (xem questions.md, Nền còn thiếu).
