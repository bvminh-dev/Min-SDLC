## Các bước
- **Given** một nhánh thử thêm vào `apps/api/src/modules/sales` dòng `import { PrismaService }` hoặc câu `$queryRaw` có `FROM orders`
- **When** chạy script lint ranh giới module của CI (SB-35) trên nhánh đó
- **Then** Script thoát mã khác 0 và nêu tệp, dòng vi phạm
- **Then** Cùng script trên nhánh sạch thoát mã 0

## Dữ liệu và ghi chú
Mẫu quét: (1) import `PrismaService` hoặc `@prisma/client` trong module `sales`; (2) chuỗi SQL chứa tên bảng của module khác. Dữ liệu mồi chung: sale S1 và S2, admin AD1, staff ST1, customer C1 (`an.nguyen@shop.vn`, `0901234567`, tên Nguyễn An); sản phẩm P1 "Áo thun cotton" `price` 150.000, `cost_price` 90.000, `on_hand` 50; P2 "Tất cổ cao" `price` 50.000, `on_hand` 3; SM1 "Giao tiêu chuẩn" `base_fee` 30.000 `free_over` 500.000, SM2 "Giao nhanh" `base_fee` 50.000; nguồn `facebook`, `tiktok`, `hotline` đang bật. PRD, INV, SHP, ORD, USR dùng module thật trên PostgreSQL; chỗ cần gài lỗi hay chậm dùng `jest.spyOn` trên lớp thật (`CatalogApi`, `InventoryApi`, `AuditService`).
