## Các bước
- **Given** A có `on_hand` 5, `reserved` 2 (nên `available` 3)
- **When** S1 tạo đơn A x 4, rồi A x 3, rồi A x 1
- **Then** A x 4: 409 `insufficient-stock` với `requested` 4, `available` 3
- **Then** A x 3: 201, `available` thành 0
- **Then** A x 1: 409 `insufficient-stock` với `available` 0
