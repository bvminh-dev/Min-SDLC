## Các bước
- **Given** Coupon FIX50K fixed value=50000 active
- **When** POST tạo coupon type=fixed kèm max_discount=10000; PATCH FIX50K {"version":1,"max_discount":20000}
- **Then** Cả hai nhận 400 với errors có field="max_discount"
- **Then** FIX50K không đổi (max_discount vẫn rỗng, version vẫn 1); thử INSERT trực tiếp type=fixed max_discount=1 vào CSDL bị CHECK từ chối

## Dữ liệu và ghi chú
Kiểm cả schema ở API và CHECK nhiều cột ở CSDL.
