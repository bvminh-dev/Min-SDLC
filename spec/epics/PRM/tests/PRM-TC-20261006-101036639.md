## Các bước
- **Given** Admin đăng nhập
- **When** POST type="percentage" lần lượt với value=101, value=0, value=10.5, value="10" (chuỗi) và các trường khác hợp lệ
- **Then** Cả bốn nhận 400 với errors có field="value"; không tạo dòng nào
- **Then** Thử INSERT trực tiếp vào CSDL type=percentage value=101 bị CHECK từ chối (lớp CSDL cũng chặn)

## Dữ liệu và ghi chú
Kiểm cả hai lớp: schema ở biên API và CHECK ở CSDL (SB-11).
