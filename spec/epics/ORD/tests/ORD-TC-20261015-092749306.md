## Các bước
- **Given** SAL mở `tx` cho sale S1; nguồn `facebook` đang bật (`source_code` = `facebook`); hai dòng hàng ("Áo thun" 100000 x 2 ghi chú "size M, màu đen" `cost_snapshot` 60000; "Quần jean" 250000 x 1 không ghi chú `cost_snapshot` 150000), `items_total` 450000, `discount` 0, `shipping_fee` 30000, `grand_total` 480000; `customer_snapshot` { "Trần Thị Mai", "0912345678" }; `shipping_address` đủ sáu khóa; `payment_method` `cod`; ghi chú đơn "Khách muốn giao sau 18h"; `created_by` = S1, `created_by_role` = `sale`, `user_id` rỗng
- **When** SAL gọi `OrderApi.createHo(input, tx)` rồi commit
- **Then** trả `{ order_id, code }` với `code` khớp `^HD[0-9]{6}-[0-9]{5}$`; `orders.status` = `confirmed`, `user_id` NULL, `created_by` = S1, `source_id` = nguồn `facebook`, `customer_snapshot` = { `full_name`, `phone` }, `note` đúng chuỗi, `payment_status` = `pending`, `payment_expires_at` NULL, `confirmed_at` có giá trị; `order_items` có 2 dòng với `note` và `cost_snapshot` đúng, `position` 1 và 2
- **Then** `order_status_history` có đúng hai dòng theo `seq`: `pending` (`from_status` NULL, `actor_id` = S1, `actor_role` = `sale`) rồi `confirmed` (`from_status` = `pending`, `actor_role` = `system`)
- **Then** `outbox_events` có OrderCreated rồi OrderConfirmed của đơn; OrderCreated có `user_id` null, `source` = `facebook`, `created_by` = S1, `payment_method` = `cod`, `payment_expires_at` null, `items` không có `note` hay `cost_snapshot`; có đúng một audit `order.created_ho` không chứa tên, điện thoại hay ghi chú
- **When** admin gọi `GET /api/v1/orders/{code}` và sale S1 gọi cùng route
- **Then** admin thấy `items[].cost_snapshot`; S1 không có khóa `cost_snapshot` trong phản hồi (khóa vắng, không phải null)

## Dữ liệu và ghi chú
Dùng PostgreSQL thật; ORD không gọi module khác trong `tx`. INV `reserve` do SAL gọi (kiểm ở TC của SAL). `payment_status` `pending` vì ORD không tự đặt `succeeded` (ORD-REQ-20261015-092748715 BR2).
