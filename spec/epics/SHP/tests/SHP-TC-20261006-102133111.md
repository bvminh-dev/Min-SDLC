## Các bước
- **Given** admin đăng nhập, đã có "Giao nhanh"
- **When** POST /api/v1/admin/shipping/methods lần lượt với: name = "" ; name = chuỗi 81 ký tự "a"; `base_fee` = -1; `base_fee` = 30000.5; `base_fee` = "30000" (chuỗi); `base_fee` = 1000001; `surcharge` = 20000 với `surcharge_cities` = []; `surcharge` = 500001; `free_over` = -5; `surcharge_cities` có 64 phần tử; body thêm trường lạ `is_active` = false; body thêm `version` = 7
- **Then** mỗi lời gọi nhận 400 `validation-failed` với lỗi nêu đúng trường sai, không tạo dòng nào (số dòng `shipping_methods` vẫn 1); riêng POST với name = "giao nhanh" (khác hoa thường với "Giao nhanh") nhận 409 tên đã dùng; POST với name = `<img src=x onerror=alert(1)>` (hợp lệ về độ dài) nhận 201 và GET trả lại đúng chuỗi đó nguyên văn trong JSON (dữ liệu không bị biến đổi, việc escape làm ở giao diện)

## Dữ liệu và ghi chú
Kiểm cả CHECK ở CSDL bằng chèn thẳng `base_fee` = -1 qua SQL: bị từ chối bởi ràng buộc. Ca name = HTML kiểm không bị log nguyên văn nội dung tên ở mức info.
