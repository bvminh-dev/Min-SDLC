## Các bước
- **Given** "Giao tiêu chuẩn": `base_fee` 30000, `free_over` 500000, `surcharge` 20000, `surcharge_cities` ["Hà Giang"]
- **When** quote với (`city` "Hà Giang", `subtotal` 500000) và (`city` "Hà Giang", `subtotal` 499999)
- **Then** lần đầu `fee` = 0 (miễn phí thắng phụ thu, 500000 >= 500000); lần sau `fee` = 50000

- **Given** phương thức B có `free_over` = 0 và phương thức C có `free_over` = null, cùng `base_fee` 30000
- **When** quote B với `subtotal` = 0, quote C với `subtotal` = 10000000000
- **Then** B trả `fee` = 0 (0 >= 0); C trả `fee` = 30000

- **Given** `surcharge_cities` ["Hà Giang"]
- **When** quote với `city` "Hà", `city` "Hà Giang 2", `city` "HA GIANG" (không dấu)
- **Then** "Hà" và "Hà Giang 2" không khớp nên `fee` = `base_fee`; "HA GIANG" khớp nên `fee` = `base_fee` + 20000

## Dữ liệu và ghi chú
Kiểm cả tên có "Đà Nẵng" so với "da nang" (chữ `đ` thay bằng `d`) khi thêm vào danh sách phụ thu.
