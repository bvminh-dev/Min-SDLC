## Các bước
- **Given** customer A chưa từng thêm gì
- **When** A gọi GET /api/v1/cart và GET /api/v1/cart/summary
- **Then** giỏ: 200 với `cart_id` = null, `items` = [], `subtotal` = 0, `total` = 0, `can_checkout` = false; huy hiệu: `{ line_count: 0, item_count: 0 }`
- **Then** CSDL không có bản ghi `carts` của A

## Dữ liệu và ghi chú
Dữ liệu mồi theo phần Given; PRD, INV, PRM, SHP dùng bản giả có đếm lời gọi.
