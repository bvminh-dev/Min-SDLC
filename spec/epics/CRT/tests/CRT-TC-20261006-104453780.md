## Các bước
- **Given** SM1 `base_fee` 30000, `free_over` 500000; giỏ đã chọn SM1; `subtotal` lần lượt 499999 rồi 500000
- **When** A xem giỏ ở từng mức
- **Then** 499999: `fee` = 30000, `free_shipping` = false; 500000: `fee` = 0, `free_shipping` = true

## Dữ liệu và ghi chú
Dữ liệu mồi theo phần Given; PRD, INV, PRM, SHP dùng bản giả có đếm lời gọi.
