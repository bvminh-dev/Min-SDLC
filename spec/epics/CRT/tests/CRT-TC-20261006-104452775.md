## Các bước
- **Given** giỏ của A: L1 P1 x 2 với `unit_price` lưu 140000; PRD vừa đổi giá P1 thành 150000
- **When** A gọi GET /api/v1/cart, rồi POST /api/v1/cart/refresh-prices
- **Then** GET: L1 `unit_price` = 150000, `previous_unit_price` = 140000, `price_changed` = true, `line_total` = 300000, `subtotal` = 300000, `price_changed` của giỏ = true
- **Then** refresh-prices: 200 với L1 không còn `previous_unit_price`, `price_changed` = false, `subtotal` vẫn 300000, `quantity` vẫn 2; `cart_items.unit_price` = 150000

## Dữ liệu và ghi chú
Dữ liệu mồi theo phần Given; PRD, INV, PRM, SHP dùng bản giả có đếm lời gọi.
