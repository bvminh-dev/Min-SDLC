## Các bước
- **Given** giỏ của A có P1 x 1 giá 100000; mã FIX100 `fixed` giá trị 100000 áp được (`discount` = 100000); phương thức SM1 miễn phí vận chuyển từ 100000 (`fee` = 0)
- **When** A xem giỏ, rồi CHK gọi `snapshotForCheckout(A)`
- **Then** giỏ trả `subtotal` = 100000, `discount` = 100000, `shipping_fee` = 0, `total` = 0, `total_is_estimate` = false; không có lỗi 4xx hay 5xx ở CRT
- **Then** `snapshotForCheckout` trả `items_subtotal` = 100000 và `can_checkout` = true (CRT không chặn tổng 0); việc chặn đơn 0 đồng (422 `zero-total-unsupported`, R-03) thuộc CHK

## Dữ liệu và ghi chú
Bản giả PRM trả `discount_amount` = 100000, bản giả SHP trả `{ fee: 0, free_shipping: true }`. Ngưỡng miễn phí tính trên tạm tính trước giảm giá (100000), không phải sau giảm.
