## Các bước
- **Given** giỏ của A có L2: P2 x 1; INV trả P2 = 0; P3 `active` INV trả P3 = 4
- **When** A xem giỏ; rồi A thêm P3 x 5
- **Then** L2 `availability.status` = `out_of_stock`, `checkout_blockers` có `insufficient_stock`, `can_checkout` = false
- **Then** thêm P3 x 5: 409 `insufficient-stock` với `available` = 4; giỏ không có P3

## Dữ liệu và ghi chú
Dữ liệu mồi theo phần Given; PRD, INV, PRM, SHP dùng bản giả có đếm lời gọi.
