## Các bước
- **Given** INV trả P1 = 5000 và P2 = 98; giỏ của A trống
- **When** A thêm P1 x 200; rồi thêm P1 x 99; rồi gọi GET /api/v1/cart; rồi thêm P2 x 99
- **Then** thêm P1 x 200: 400 (vượt 99, trước khi kiểm tồn); thêm P1 x 99: 201
- **Then** GET /api/v1/cart: dòng P1 có `availability` = `{ status: "ok" }` và không có khóa `available`
- **Then** thêm P2 x 99: 409 `insufficient-stock` với `available` = 98; quét mọi body phản hồi trên không thấy số 5000

## Dữ liệu và ghi chú
Quét đệ quy JSON phản hồi tìm khóa `available` và assert nhỏ hơn hoặc bằng 99.
