## Các bước
- **Given** `u3` vừa đăng ký, `email_verified_at` rỗng, `phone` rỗng
- **When** `u3` gửi `GET /api/v1/me`
- **Then** trả 200 với `email_verified` = false, `phone` = null, `avatar_url` = null

- **Given** `u1` đang có phiên hợp lệ, rồi admin khóa `u1`
- **When** `u1` gửi `GET /api/v1/me` bằng cookie cũ
- **Then** trả 401 (khóa thu hồi mọi phiên), thân không có dữ liệu hồ sơ

## Dữ liệu và ghi chú
Khóa bằng `POST /api/v1/admin/users/{id}/lock` của AUTH hoặc cập nhật trực tiếp trong fixture.
