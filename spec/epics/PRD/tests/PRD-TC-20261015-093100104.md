## Các bước
- **Given** Sản phẩm `active` có `cost_price` = 90000, `version` = 5
- **When** Admin gửi `cost_price` = null kèm `version` = 5, rồi gửi `cost_price` = 0 kèm `version` = 6
- **Then** Lần một `cost_price` = null và `version` = 6; lần hai `cost_price` = 0 và `version` = 7; hai bản ghi audit, mỗi bản có giá trị trước và sau
