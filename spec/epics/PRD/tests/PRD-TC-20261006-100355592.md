## Các bước
- **Given** Sản phẩm "Áo thun cotton" active, price 150000, version 3
- **When** PATCH /api/v1/admin/products/<id> {version:3, price:120000}
- **Then** Nhận 200 với price = 120000, version = 4; GET /products/<id> trả price = 120000; AuditLog ghi giá cũ 150000 và giá mới 120000, người làm là admin
