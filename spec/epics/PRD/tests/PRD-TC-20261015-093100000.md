## Các bước
- **Given** Admin đã đăng nhập; chưa có sku "AT-010"; danh mục "Áo" tồn tại
- **When** Admin tạo sản phẩm `sku` = "AT-010", `price` = 150000, `cost_price` = 90000
- **Then** Nhận 201 với `cost_price` = 90000, `price` = 150000, `status` = `draft`; chi tiết quản trị đọc bằng admin có `cost_price` = 90000; bản ghi audit tạo có giá vốn 90000; không có event nào trong outbox

## Dữ liệu và ghi chú
Dữ liệu mồi dựng bằng fixture của test; không phụ thuộc test khác.
