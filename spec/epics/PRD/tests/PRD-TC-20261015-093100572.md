## Các bước
- **Given** Admin đã đăng nhập; tệp có dòng `Tên hàng` = "Áo <script>alert(1)</script>", các ô khác hợp lệ
- **When** Admin import rồi mở danh sách quản trị
- **Then** Tên lưu đúng chuỗi gốc; phản hồi JSON giữ nguyên chuỗi; DOM hiển thị bằng nút văn bản (không có phần tử `script`, không chạy mã)

## Dữ liệu và ghi chú
Dữ liệu mồi dựng bằng fixture của test; không phụ thuộc test khác.
