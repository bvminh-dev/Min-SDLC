## Các bước
- **Given** Sản phẩm vừa chuyển archived; sản phẩm active chưa có đánh giá; sản phẩm mô tả rỗng; sản phẩm mô tả đúng 5000 ký tự
- **When** GET lần lượt từng sản phẩm
- **Then** Archived: 404. Chưa có đánh giá: rating_count = 0, rating_avg = null. Mô tả rỗng: description rỗng hoặc vắng. 5000 ký tự: trả đủ 5000 ký tự

## Dữ liệu và ghi chú
Dữ liệu mồi dựng bằng fixture của test; không phụ thuộc test khác.
