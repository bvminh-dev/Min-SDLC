## Các bước
- **Given** Admin đã đăng nhập; tệp có ba dòng: tên 201 ký tự emoji, tên chứa ký tự NUL, tên chứa tab ở giữa
- **When** Admin gửi với `dry_run=true`
- **Then** Dòng tên 201 emoji `error` `name_invalid`; dòng NUL `error` `name_invalid`; dòng tab giữa tên `error` `name_invalid` (không ký tự điều khiển)

## Dữ liệu và ghi chú
Dữ liệu mồi dựng bằng fixture của test; không phụ thuộc test khác.
