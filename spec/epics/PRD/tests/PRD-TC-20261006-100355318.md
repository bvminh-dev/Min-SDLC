## Các bước
- **Given** CSDL bị chặn kết nối (giả lập)
- **When** GET /api/v1/categories
- **Then** Nhận 503 với Content-Type application/problem+json có trace_id; body không chứa chuỗi stack, tên bảng hay câu SQL
