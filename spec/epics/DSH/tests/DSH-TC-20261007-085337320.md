## Các bước
- **Given** một cây mã mẫu trong đó tệp của module `dashboard` import `../order/internal/order.repository` (ORD nằm trong cột Phụ thuộc nhưng file không phải điểm vào công khai)
- **When** chạy `node scripts/check-boundaries.mjs --modules <cây mẫu>`
- **Then** thoát mã khác 0 và in tệp, dòng kèm "import file bên trong order; chỉ được import điểm vào công khai (index.ts)"

## Dữ liệu và ghi chú
Mẫu quét riêng cho import file nội bộ, tách khỏi ca import module ngoài Phụ thuộc.
