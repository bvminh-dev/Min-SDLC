## Các bước
- **Given** ORD giả có bốn đơn tạo trong 2026-10-01 tới 2026-10-06: O1 `paid` `payment_status` `succeeded` `grand_total` 100000; O2 COD `returned` (PAY đã đóng Payment COD `pending -> cancelled` khi nhận OrderReturned) `payment_status` `cancelled` `grand_total` 250000; O3 `cancelled` do hệ thống (`cancel_reason` `stock_commit_failed`, `cancelled_by_role` `system`) `payment_status` `refunded` `grand_total` 400000; O4 `delivered` `payment_status` `succeeded` `grand_total` 300000
- **When** admin gọi `GET /api/v1/admin/reports/orders?from=2026-10-01&to=2026-10-06`
- **Then** 200 với `totals.total` = 4; `totals.by_status` đủ tám khóa: `paid` 1, `delivered` 1, `returned` 1, `cancelled` 1, `pending` 0, `confirmed` 0, `shipped` 0, `expired` 0; `cancel_rate` = 25.0; `average_order_value` = 200000 ((100000 + 300000) / 2, O2 và O3 bị loại)
