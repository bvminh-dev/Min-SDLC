- **When** admin xem báo cáo theo nguồn
- **Then** 200; `items` đúng hai dòng `website`, `facebook` đều 0 đơn 0 đ; `totals` `{ orders: 0, revenue: 0, excluded_orders: 0 }` (không phải lỗi, không phải `null`)
