## Các bước
- **Given** admin đã gửi 30 yêu cầu trong phút hiện tại (`DASHBOARD_RATE_LIMIT_PER_MINUTE`) và đang ở `/admin/reports/sources`
- **When** admin bấm `dsh-analytics-sources-range-apply`
- **Then** `dsh-analytics-sources-rate-limit` hiện dòng "Thao tác quá nhanh, thử lại sau N giây" với N bằng `Retry-After`, bảng cũ vẫn còn, không hiện số 0 thay số thật
- **When** hết N giây rồi bấm `dsh-analytics-sources-range-apply` lại
- **Then** `dsh-analytics-sources-rate-limit` biến mất, báo cáo tải lại (200) và `dsh-analytics-sources-table` có số mới
- **When** admin bấm `dsh-analytics-sources-export-csv` khi ORD chậm
- **Then** `dsh-analytics-sources-export-loading` hiện và nút khóa; tệp tải xong thì nút mở lại, `dsh-analytics-sources-export-loading` không còn
- **When** admin bấm `dsh-analytics-sources-export-csv` khi API trả 503
- **Then** `dsh-analytics-sources-export-error` hiện, không tải tệp rỗng, nút mở lại để bấm lần nữa

## Dữ liệu và ghi chú
Trang web chạy trên API thật và PostgreSQL thật (ADR-002); lỗi gài bằng `jest.spyOn` trên `OrderApi`; đồng hồ cố định ở 2026-10-15T03:00:00Z; đăng nhập bằng tài khoản admin có sẵn; testid lấy từ ui `analytics-sources`, `analytics-sales` (spec/testids.md do lead sinh sau khi duyệt ui).
