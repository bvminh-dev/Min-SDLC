# Ca: triển khai epic PRJ

Epic PRJ (Project prepare) đã có: 6 requirement, flow, DB/API/SEC, test case (không có màn). Khung dự án theo ADR-002 (NestJS API + Next.js web, monorepo pnpm) có thể chưa có: task đầu tiên là dựng đúng khung.
Yêu cầu: chạy `sdlc-implement` cho epic PRJ, không hỏi lại người dùng; chỗ spec thiếu hoặc sai ghi `Lệch spec`.
Điều kiện cần có trước: nền và tài liệu epic ở trạng thái `approved`.
